Day in brief

OAuth migration endpoints and mailbox limits lead this Exchange update

The period delivered two substantive administrator guides: one covering OAuth authentication for Microsoft 365 Mailbox Replication Service migrations and another documenting Exchange Online message-size limits. Message Center notices also cover a policy-controlled unified inbox in new Outlook, Outlook event duplication, and custom profile-card properties planned for January 2027.

  • Hybrid · Email authentication and transport security
    OAuth authentication is documented for MRS migration endpoints

    A new Hybrid guide explains how Microsoft 365 Mailbox Replication Service can use OAuth for migrations between Microsoft 365 and on-premises Exchange. It covers Entra ID application registration and supports Exchange Server Subscription Edition or Exchange 2019 CU15 with the latest ESU, together with Microsoft 365 commercial cloud. Adoption requires Entra ID access, migration-domain configuration, and registration of the on-premises API application.

  • Mail flow · General
    Exchange Online message-size guidance sets concrete defaults and limits

    The new mail-flow article documents 35 MB sending and 36 MB receiving defaults, configurable mailbox limits from 1 MB to 150 MB, and EAC and PowerShell configuration. It also explains how headers, encoding, attachments, and content conversion contribute to message overhead and the effective limit.

  • Exchange Online · General
    New Outlook adds a policy-controlled All Accounts inbox

    The All Accounts, or Unified Inbox, view in new Outlook for Windows lets users manage email from multiple accounts in one view without merging the underlying mailboxes. Administrators can enable or disable the feature through a policy in the Microsoft 365 Apps admin center and control whether users can override the setting.

  • Exchange Online · General
    Outlook is rolling out event duplication

    The new Duplicate event capability lets users create an event from an existing one without re-entering its details. Microsoft says rollout began in late September 2026 and is scheduled to finish by early December 2026; the notice calls for no administrator action or compliance changes.

  • Exchange Online · General
    Profile cards will support up to 10 third-party custom properties

    Starting in January 2027, administrators will be able to add up to 10 properties from external systems to Microsoft 365 profile cards through Microsoft Graph People connectors. The feature is off by default and requires administrator setup; later updates are planned for SAP SuccessFactors and Workday support.

Microsoft 365: Enrich profile cards with custom properties from third-party systems

New

Starting January 2027, Microsoft 365 admins can add up to 10 custom properties from external systems to profile cards via Microsoft Graph People connectors. This feature is off by default, requires admin setup, and enhances user profiles for better collaboration. Future updates will support SAP SuccessFactors and Workday.

Microsoft Outlook: New event duplication capability

New

Microsoft Outlook is adding a "Duplicate event" feature, allowing users to quickly create new events based on existing ones without re-entering details. The rollout began in late September 2026 and will complete by early December 2026. No action or compliance changes are required.

New Outlook for Windows: All Accounts view brings email into a single inbox view

New

The new Outlook for Windows offers an All Accounts (Unified Inbox) view, letting users see and manage emails from multiple accounts in one inbox without merging mailboxes.
