Oauth Migration Endpoint

11 November 2026Feature updateAction required+44 / −26 lines

In brief

The guidance now limits supported environments to Microsoft 365 multi-tenant (WW) and on-premises Exchange Server SE from October 2026 onward or Exchange 2019 CU15 with the October 2026 security update. It also changes the optional claim to `xms_aud_guid` and adds endpoint testing and move-request examples.

What Exchange admins need to know

Administrators configuring this integration must use the updated platform prerequisites and optional claim, then validate the endpoint and ensure URI host values match the migration commands.
