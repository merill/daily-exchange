Admin Api Authentication

25 November 2026RetirementAction required+14 / −10 lines

In brief

The documentation states that Exchange.ManageV2 and Exchange.ManageAsAppV2 are being retired and replaces them with Exchange.AdminAPI.Manage and Exchange.AdminAPI.ManageAsApp. It also says the described features are now generally available.

What Exchange admins need to know

Update delegated and app-only application permissions, consent, and token configuration to use the new permission names.

Note

The features described in this article are currently in Preview, aren't available in all organizations, and are subject to change.now generally available.

This article covers the authentication and authorization requirements for using endpoints for the Exchange Online Admin API.

- Delegated flow: `Exchange.ManageV2`.
- App-only flow: `Exchange.ManageAsAppV2`.

Note

`Exchange.ManageV2` and `Exchange.ManageAsAppV2` permissions are being retired. Use `Exchange.AdminAPI.Manage` for delegated access and `Exchange.AdminAPI.ManageAsApp` for app-only access. These are dedicated permissions for the Exchange Online Admin API v2.0 to provide a clearer authorization model for applications accessing these endpoints. The Exchange Online Admin API v2.0 endpoints aren't being retired; this change affects only the permissions used to access them.

  1. Step 3: Assign RBAC permissions

    Exchange Online uses role-based access control (RBAC) to determine which endpoints, cmdlets, and objects the caller can manage. Assign the appropriate RBAC roles to the user (for delegated access) or to the app's service principal (for app-only access).

  2. On the What type of permissions does your application require? flyout, make one of the following selections:

    • App-only flow: Select Application permissions, expand Exchange, select Exchange.ManageAsAppV2AdminAPI.ManageAsApp, and then select Add permissions.

    • Delegated flow: Select Delegated permissions, expand Exchange, select Exchange.ManageV2AdminAPI.Manage, and then select Add permissions.

  3. Back on the API permissions page, verify the selections from the previous step are listed:

    • Office 365 Exchange Online > Exchange.AdminAPI.ManageAsApp:
      • Type: Application
      • Admin consent required: Yes
    • Office 365 Exchange Online > Exchange.ManageV2AdminAPI.Manage:
      • Type: Delegated
      • Admin consent required: Yes

  4. Select Grant admin consent for, review the confirmation dialog, and select Yes.

Client credentials flow (app-only)

Use this flow for service-to-service calls without a user. After admin consent to application permissions (for example, Exchange.ManageAsAppV2AdminAPI.ManageAsApp) and assigning the required RBAC roles, request a token using the app's own credentials. No refresh token is issued. Request new access tokens as needed.

To acquire an access token, send a POST request to the /token identity platform endpoint. In this request, the client uses the client secret.
