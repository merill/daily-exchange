Month in brief

EWS migration deadline and Admin API changes lead Exchange Online’s November updates

November’s highest-impact changes affect cross-tenant interoperability and Exchange Online automation. Microsoft says EWS deprecation, which began October 1, 2026, affects cross-tenant Free/Busy, MailTips, and Calendar Sharing; Cross-Tenant Access Policy is expected to replace EWS by late November. Admin API v2.0 permissions and the MailboxFolderPermission response shape are also changing. Outlook on the web and new Outlook for Windows will additionally block .msix and .msixbundle files by default starting in December. Hybrid administrators received narrower OAuth migration prerequisites and a new optional claim.

  • Exchange Online · PowerShell and APIs
    Cross-tenant EWS scenarios must move to Cross-Tenant Access Policy

    EWS deprecation began October 1, 2026, affecting cross-tenant Free/Busy, MailTips, and Calendar Sharing. Microsoft expects Cross-Tenant Access Policy to replace EWS by late November; organizations should migrate to avoid disruption. The GCC rollout is paused.

  • Exchange Online · PowerShell and APIs
    Exchange Online Admin API v2.0 permissions are being replaced

    Microsoft is replacing Exchange.ManageV2 and Exchange.ManageAsAppV2 with new permissions by November 2026. Affected applications need the new permissions, admin consent, RBAC verification, and testing; administrators should remove the legacy permissions afterward. API endpoints are unchanged.

  • Exchange Online · PowerShell and APIs
    MailboxFolderPermission is changing its User response shape

    The v2.0 MailboxFolderPermission endpoint is scheduled to return User as a structured object containing DisplayName, Name, and PrimarySmtpAddress by early November 2026. Applications that consume the response must handle the new fields to avoid errors.

  • Exchange Online · General
    Outlook will block .msix packages by default in December

    Outlook on the web and new Outlook for Windows will add .msix and .msixbundle to the default blocked file types in OwaMailboxPolicy starting December 2026. Organizations that rely on these files should allow them in policy before rollout.

  • Hybrid · Planning and deployment
    Hybrid OAuth guidance narrows supported migration environments

    The updated migration-endpoint guidance documents support for Microsoft 365 multi-tenant (WW) with on-premises Exchange Server Subscription Edition from October 2026 onward, or Exchange 2019 CU15 with the October 2026 security update. It changes the optional claim to xms_aud_guid and adds endpoint-testing and move-request examples.

For Exchange administrators

Prioritize migration of affected cross-tenant scenarios and inventory applications using the Exchange Online Admin API. Update both API permission assignments and response handling, then test before removing legacy permissions. Review OwaMailboxPolicy settings if users need .msix or .msixbundle files. Hybrid teams should verify the documented platform prerequisites, use xms_aud_guid, and test migration endpoints. The month’s Outlook visual, search, event-duplication, and unified-inbox notices do not require action based on the supplied evidence.
