Microsoft 365: Enrich profile cards with custom properties from third-party systems

New

Starting January 2027, Microsoft 365 admins can add up to 10 custom properties from external systems to profile cards via Microsoft Graph People connectors. This feature is off by default, requires admin setup, and enhances user profiles for better collaboration. Future updates will support SAP SuccessFactors and Workday.

6 November 2026

Microsoft Outlook: New event duplication capability

New

Microsoft Outlook is adding a "Duplicate event" feature, allowing users to quickly create new events based on existing ones without re-entering details. The rollout began in late September 2026 and will complete by early December 2026. No action or compliance changes are required.

6 November 2026
Message CenterMC1492166 on mc.merill.net ↗Stay informed

New Outlook for Windows: All Accounts view brings email into a single inbox view

New

The new Outlook for Windows offers an All Accounts (Unified Inbox) view, letting users see and manage emails from multiple accounts in one inbox without merging mailboxes. Admins can control this feature via a policy in the Microsoft 365 Apps admin center, enabling or disabling it and user override options.

6 November 2026
Message CenterMC1519843 on mc.merill.net ↗Stay informed

Microsoft Outlook: Search within a selected folder

New

Outlook will allow users to limit search results to a selected mail folder, enhancing search control. This feature will roll out globally in mid-November 2026. No action or compliance concerns are required.

5 November 2026

2

Action required: Update permissions for Exchange Online Admin API

New

Microsoft is updating Exchange Online Admin API v2.0 permissions, replacing Exchange.ManageV2 and Exchange.ManageAsAppV2 with new permissions by November 2026. Affected applications must transition, obtain admin consent, verify RBAC roles, test, and remove old permissions to maintain access. No endpoint changes occur.

5 November 2026

Action required: Exchange Online Admin API MailboxFolderPermission response update

New

Microsoft will update the Exchange Online Admin API v2.0 MailboxFolderPermission endpoint to return the User property as a structured object with DisplayName, Name, and PrimarySmtpAddress by early November 2026. Organizations must update applications to handle this change to avoid errors.

5 November 2026
